Help me define the authorization rules and access control policies for our application:

1. Identify the different user roles and permission levels
2. Specify what resources each role can access
3. Define permissions for CRUD operations on each resource
4. Document any special conditions or dynamic permissions
5. Specify how permissions should be checked (at API level, in business logic, etc.)
6. Note any audit or logging requirements for access control
7. Define how unauthorized access attempts should be handled

These rules will ensure proper implementation of security and access control throughout the application.
