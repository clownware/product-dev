For any complex calculations or algorithms required in our application, help me create detailed specifications:

1. Define the purpose and expected output of each calculation
2. Specify the exact formula or algorithm to be used
3. Identify all input variables and their sources
4. Document any rounding rules or precision requirements
5. Note edge cases and how they should be handled
6. Specify any performance considerations
7. Suggest validation approaches to ensure accuracy

These specifications will ensure consistent implementation of critical business calculations.
