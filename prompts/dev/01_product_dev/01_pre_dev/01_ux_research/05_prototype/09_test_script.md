For testing our prototype of: "[insert solution concept]", let's create a structured test script.

Please help me develop:

1. Introduction (2-3 minutes):
   - How will we welcome and orient participants?
   - What context should we provide (without biasing results)?
   - What permissions or recording details need explanation?
   - How will we encourage honest feedback?

2. Background questions (3-5 minutes):
   - What 3-5 questions will help us understand relevant participant context?
   - How can we explore their current experience with the problem?

3. Task scenarios (15-20 minutes):
   - What 3-4 specific tasks should participants attempt?
   - For each task:
     - What exactly should they try to accomplish?
     - What is the expected successful outcome?
     - What specific aspects should we observe?
     - What follow-up questions should we ask?

4. General exploration (5-8 minutes):
   - How might we observe natural user exploration?
   - What aspects should participants try without specific direction?

5. Reflection questions (5-8 minutes):
   - What questions will help assess overall impression?
   - How will we probe on specific hypothesis elements?
   - What questions might reveal unexpected insights?

6. Closing (2-3 minutes):
   - How will we thank participants and explain next steps?
   - What final thoughts might we want to capture?

This script provides structure while allowing for organic discovery during testing sessions.
